【聆竹】音频嗅探下载器

页面上一播放音频，右下角就会弹出一条简洁提示，点一下就下载。

下载

下载前选择路径与文件名打开后每次下载都会弹出系统的「另存为」对话框，可以自己挑文件夹、改文件名
默认下载路径浏览器下载目录之内的子文件夹，例如 音频下载 或 音乐/语音；留空表示直接存到下载目录根下

浏览器不允许扩展指定下载目录之外的绝对路径（比如 D:\Music），传了会被拒绝。要换盘符或根目录，请改浏览器自己的下载位置：Edge 里打开 edge://settings/downloads。

上面的「选择路径」对普通音频文件生效；网页内部实时合成的音频（下载时走页面内保存）不弹对话框，会直接存到下载目录。

提示行为

播放音频时自动弹出提示卡片关闭后仍可在工具栏图标里手动下载
卡片自动消失时间（秒）0 表示一直显示，直到手动关闭；鼠标悬停时不会消失
连续播放多久才提示（秒）0 = 不过滤（默认）；想过滤掉按钮音效、提示音等短音就填个 1~2
音频总时长下限（秒）0 = 不过滤（默认）；用 new Audio() 播放的内容不受此项限制
纯嗅探兜底：也弹卡片页面里连播放器元素都没有（纯 Web Audio / XHR 取音频）时，靠网络嗅探也能提示；页面本身能检测到播放时此项不会打扰你
卡片出现位置也可以直接用鼠标把卡片拖到任意位置
只在页面主框架显示卡片避免页面内嵌小窗口（iframe）里弹出看不清的卡片
工具栏图标显示已发现数量角标数字为当前标签页发现的音频条数
已保存 ✓

怎么用

  1. 在网页上点播放（音乐、播客、视频里的声音都行）。
  2. 页面角落弹出一条简洁卡片，显示音频名字。
  3. 点 下载：文件会存到「下载 / 音频下载」文件夹。若该地址被服务器拒绝，扩展会自动改用页面内下载兜底。
  4. 没弹卡片？点一下工具栏图标，里面列着当前页发现的所有音频，可以逐条下载。

Edge 安装步骤（开发人员模式）

  1. 地址栏输入 edge://extensions/ 回车。
  2. 打开左下角的 开发人员模式。
  3. 点 加载解压缩的扩展，选择本扩展所在文件夹（含 manifest.json 的那一层），确定。
  4. 把「【聆竹】音频嗅探下载器」固定到工具栏：点地址栏右侧的拼图图标 → 点旁边的图钉。
  5. 装好后建议把 edge://extensions/ 里本扩展的 允许访问文件 URL 打开，这样本地 html 文件也能用。

注意：Chrome / Edge 应用商店之外的扩展重启浏览器不会失效，但如果把扩展文件夹移动或删除，扩展会失效，需要重新加载。

已知限制

  • 只做下载，不做录音。
  • 加密（DRM/Widevine）音频无法下载，这是浏览器安全限制。
  • 网站若用 MSE 分片流播放（部分音乐/视频站），音频是边下边拼的，没有完整的文件地址，无法直接下载；这类条目会在工具栏面板里标注「分片流，无法直接下载」。
  • 扩展内下载会忽略网站的防盗链 Referer，少数站点首次下载失败时会自动回退到页面内下载。
