# 【聆竹】音频嗅探下载器（Edge / Chrome 扩展）

网页上一播放音频，页面角落就弹出一条**简洁卡片**：显示音频名字 + 一个下载按钮。
点一下就能把正在播放的音频存下来。**只做下载，不做录音。**

- **扩展文件夹**：`extension/`（加载扩展时选这个文件夹）
- **安装包**：`【聆竹】音频嗅探下载器-v1.2.0.zip`
- 已用 **Edge 154 + Chrome** 实测加载通过，扩展 ID 固定为 `peonfakknfpeeeojndpijncnkjkgnohi`
- 能抓住**从不插入 DOM 的 `new Audio()` 播放器**（米游社 wiki 角色语音这类），也支持 iframe 内播放

---

## 一、装到 Edge 上（约 30 秒）

1. 打开 Edge，地址栏输入 `edge://extensions/` 回车。
2. 打开左下角的 **开发人员模式**。
3. 点 **加载解压缩的扩展**，选择本目录下的 **`extension`** 文件夹（里面有 `manifest.json` 的那一层）。
4. 点地址栏右边的**拼图图标** → 找到「【聆竹】音频嗅探下载器」→ 点**图钉**固定到工具栏。
5. 建议再点扩展卡片上的 **详细信息**，把 **允许访问文件 URL** 打开（这样本地 `file://` 打开的网页也能用）。

> Chrome 用户：打开 `chrome://extensions/`，其余步骤一样。

> **已经装过旧版要更新**：把 `extension` 文件夹覆盖成新的，然后到 `edge://extensions/` 点这个扩展卡片上的 **重新加载** 图标。

## 二、怎么用

### 挂在页面上（主要方式）
页面上点播放 → 右下角弹出卡片「歌名.mp3」→ 点 **下载**。
文件存到浏览器下载目录下的 **`音频下载`** 文件夹里，中文文件名正常。

卡片会自己在十几秒后消失；鼠标停在卡片上不会消失，也可以按住卡片拖到顺手的位置。

### 从工具栏面板下载（补充方式）
点工具栏上的扩展图标，面板里列出**当前页面发现过的全部音频**，逐条下载。
没弹卡片时就来这里看——例如同一地址 5 分钟内只提示一次，或用的是内嵌播放器。

## 三、设置（工具栏图标 → ⚙）

### 下载

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 下载前选择路径与文件名 | 关 | 打开后每次下载都弹系统「另存为」对话框，可自己挑文件夹、改文件名 |
| 默认下载路径 | `音频下载` | 浏览器下载目录**之内**的子文件夹，可写多层，如 `音乐/语音`；留空 = 直接存到下载目录根下 |

### 提示行为

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 播放音频时自动弹出提示卡片 | 开 | 关掉后仍可从工具栏面板手动下载 |
| 卡片自动消失时间 | 12 秒 | 0 = 一直显示；鼠标停在卡片上不会消失 |
| 连续播放多久才提示 | **0 秒** | 0 = 不过滤。想滤掉按钮音效就填 1~2 |
| 音频总时长下限 | **0 秒** | 0 = 不过滤。`new Audio()` 播放的内容不受此项限制 |
| 纯嗅探兜底：也弹卡片 | 开 | 页面里连播放器元素都没有（纯 Web Audio）时，靠网络嗅探也能提示 |
| 卡片出现位置 | 右下角 | 也可以用鼠标把卡片拖到任意位置 |
| 只在页面主框架显示 | 开 | 避免内嵌小窗口里弹出看不清的卡片 |
| 工具栏图标显示数量 | 开 | 角标是当前页发现的音频条数 |

### 「默认下载路径」为什么不能填 `D:\Music`？

**浏览器不允许。**扩展的下载 API 只接受浏览器下载目录**之内**的相对路径，这是 Chromium 的硬限制。
本机实测（`test/probe-download2.js`）：

| 传给浏览器的 filename | 结果 |
| --- | --- |
| `音频下载/probe1.mp3` | ✅ 成功，子目录自动创建 |
| `音乐/语音/probe2.mp3` | ✅ 多层子目录也照样创建 |
| `测试曲目.mp3` | ✅ 中文文件名正常 |
| `D:\Music\probe4.mp3` | ❌ 报错 `Invalid filename` |
| `../escape/probe5.mp3` | ❌ 报错 `Invalid filename` |

所以这一项只填**下载目录下的子文件夹**。填了盘符或开头的斜杠，扩展会自动去掉再下载，不会让下载失败
（见 `test/e2e-download.js` 里的传参核对）。真想换盘符或根目录，改**浏览器自己**的下载位置：
Edge 打开 `edge://settings/downloads`。

另外，网页内部实时合成的音频（走页面内保存那条路）不会弹「另存为」对话框，会直接存到下载目录 ——
`<a download>` 既不能指定目录，也不受扩展控制。

## 四、常见问题

**没弹卡片？**
1. 音频得**真的在出声**——静音播放、被浏览器拦下的自动播放都不会提示。
2. 同一个地址 5 分钟内只提示一次，避免刷屏；直接点工具栏图标看列表即可。
3. 网站用 **MSE 分片流**播放的音频没有完整文件地址，按设计不弹卡片（避免每次点都失败），
   面板里会标注为「分片流，无法直接下载」。
4. 如果你把「连续播放多久才提示」「音频总时长下限」调成了非 0，太短的音频会被过滤；改回 0 即不过滤。

**卡片显示的名字不对？**
名字优先取网站自己声明的歌名（`mediaSession`），其次取"你刚点击的那一行"的标题，
再退到网页标题。想改名直接改下载下来的文件名即可。

**点下载提示"下载失败"？**
扩展会自动改用「页面内下载」再试一次（自带 Referer / Cookie）。
若仍失败，说明服务器对该地址做了防盗链、需要登录，或音频是网页实时合成的。

**支持哪些浏览器？**
Edge / Chrome / 其他 Chromium 内核浏览器（Brave、Vivaldi 等），需要 116 或更高版本。
Firefox 需要另做适配（用的是 Manifest V2 API 风格）。

## 五、已知限制

- **只做下载，不做录音**（v1.2.0 起按需求移除了录制功能）。
- **DRM / 加密音频**（Widevine、EME）无法下载，这是浏览器安全限制。
- 网站若用 **MSE 分片流**播放（部分音乐/视频站），音频是边下边拼的，没有完整文件地址，无法直接下载。
- 少数站点防盗链严格，直连下载会被拒绝（扩展会自动兜底一次）。
- 首次安装时会申请「读取所有网站数据」权限——因为扩展需要嗅探任意网站的音频请求，这是同类扩展的必要权限。

## 六、目录结构与原理

```
extension/
├── manifest.json          Manifest V3 配置（permissions: downloads/tabs/webRequest/activeTab）
├── icons/                 图标（16/32/48/128）
└── src/
    ├── background.js      Service Worker：webRequest 嗅探音频请求、调度下载、汇总标签页数据、角标
    ├── page-hook.js       页面主世界钩子：挂 play()/new Audio()，抓游离元素
    ├── content.js         内容脚本：接收播放事件 → 上报 → 渲染简洁卡片 + 页面内下载兜底
    ├── popup.html/js      工具栏面板：当前标签页音频列表
    └── options.html/js    设置页
test/e2e.js                端到端自检（常规 <audio> 页面）
test/e2e-detached.js       端到端自检（游离 new Audio() + blob 下载）
test/e2e-mihoyo.js         真实站点自检（米游社 wiki 角色语音页）
test/e2e-download.js       下载设置自检（子目录 / 另存为 / 设置迁移）
test/e2e-ui.js             面板/设置页冒烟测试
test/probe-download.js     探针：CDP setDownloadBehavior 会劫持文件命名的反例
test/probe-download2.js    探针：下载 API 的 filename 规则（子目录 / 绝对路径 / saveAs）
tools/make_icons.py        图标生成脚本
tools/build_zip.py         打包脚本（生成可分发的 zip）
```

**工作流程**

1. **主世界钩子**（`page-hook.js`，`world: MAIN`，document_start）直接改写
   `HTMLMediaElement.prototype.play`、`window.Audio`、`document.createElement`。
   为什么必须这么做：很多播放器用 `new Audio()` 创建**从不插入 DOM 的游离元素**
   （米游社 wiki 角色语音就是），游离元素的 `play` 事件根本不流经 `document`，
   `querySelector` 也找不到它 —— 只有主世界钩子才看得见。
2. 钩子把播放事件 `postMessage` 给内容脚本，内容脚本连同 DOM 里的 `<audio>/<video>` 检测一起上报后台。
   标题优先取 `navigator.mediaSession.metadata`，没有就顺着"刚点击的那一行"取名字。
3. 后台同时用 `chrome.webRequest` 记录音频响应（Content-Type、文件大小、是否分片流），与上报记录合并。
4. 下载时按地址类型分流：
   - `http(s)` → `chrome.downloads` 直连下载（不受页面 CORS 限制，文件名自动生成，支持中文）；
   - `blob:` → 交给页面内 `fetch` 取回原始字节再保存（blob 地址属于页面，后台下载不了）；
   - 直连下载被服务器拒绝 → 回退到「页面内 fetch → blob 下载」（自带页面 Referer / Cookie）；
   - 分片流（`stream`）→ 面板里标注为不可下载。
5. 卡片渲染在主框架（iframe 里的媒体也会把卡片弹到主框架上，保证看得见）。

## 七、自检结果（本机 Edge 154 无头实测）

| 自检脚本 | 结果 | 关键证据 |
| --- | --- | --- |
| `node test/e2e-download.js` | **19/19 通过** | 默认子目录、多层子目录、留空落根下都实测落盘；绝对路径/`..`/非法字符被规整（传参核对）；`saveAs` 开关确实传给了浏览器；旧默认值 2/3 被迁移成 0 且不覆盖用户自己设过的值 |
| `node test/e2e-mihoyo.js` | **11/11 通过** | 真实米游社页面：`audioTags=0`、钩子注入、卡片标题取到语音名 **「初次见面」**，落盘为 **`音频下载\初次见面.wav`（1 011 308 字节）** |
| `node test/e2e-detached.js` | **11/11 通过** | 游离 `new Audio()`：`detached=true fromHook=true`；blob 下载落盘 **192 044 字节真 wav**（扩展名由真实 MIME 推导） |
| `node test/e2e-ui.js` | **9/9 通过** | 面板与设置页均无 JS 报错、无任何录制相关 UI，新默认值读取正确 |
| `node test/e2e.js` | 10/11 通过 | 常规 `<audio>` 页面全通过；唯一失败项是**本机 localhost 直连下载**：本机沙箱存在 HTTP 中间层把 localhost 响应改写成 `204`，导致浏览器下载报错、`fetch` 拿到 0 字节。**外网 HTTPS 下载已实测成功**（见米游社 1 MB 文件），属运行环境问题而非扩展问题 |

> 写测试时踩到的一个坑：CDP 的 `Browser.setDownloadBehavior` 会**劫持文件命名**——
> 扩展传的 `filename` 被忽略，所有文件都落成 URL 里的原名，子目录也不创建。
> 用它做测试会得出「文件名设置没生效」的错误结论。现在 `e2e-download.js` 与 `e2e-mihoyo.js`
> 都改用 profile 里的 `Preferences` 指定下载目录（见 `test/probe-download.js` 的反例对比）。

> 重新生成图标：`python tools/make_icons.py`
> 重新打包：`python tools/build_zip.py`（生成 `【聆竹】音频嗅探下载器-v<版本号>.zip`，`manifest.json` 位于压缩包根目录）

## 八、更新日志

### v1.3.0
- **新增**：设置项「**下载前选择路径与文件名**」。打开后每次下载都会弹系统「另存为」对话框，
  可以自己挑文件夹、改文件名（用户取消对话框时会提示「已取消下载」，不会误报失败）。
- **新增**：设置项「**默认下载路径**」。浏览器下载目录之内的子文件夹，支持多层（如 `音乐/语音`），
  留空则直接存到下载目录根下。填了绝对路径或 `..` 会自动规整成合法相对路径，不会让下载失败。
- **调整**：**「连续播放多久才提示」与「音频总时长下限」的默认值改成 0**（即默认不做任何过滤）。
  老用户 storage 里存着的旧默认值 2/3 会自动迁移成 0；自己手动调过的值不会被覆盖。
- **优化**：卡片上的按钮下载成功后 4 秒恢复成「下载」，可以再存一份，或在「另存为」里取消后直接重来。
- **优化**：重名策略显式设为 `uniquify`，已有文件不会被静默覆盖。

### v1.2.0
- **移除**：录制功能（页面内录制 + 整页标签页录制）及其全部设置项、`offscreen`/`tabCapture` 权限、离屏文档。
  插件现在只做下载，权限更少、代码更简单。
- **调整**：只有「可直接下载的文件」才自动弹卡片；分片流只在工具栏面板里列出并标注「不可下载」，
  不再出现点了必然失败的按钮。
- **改进**：`blob:` 音频改由页面内 `fetch` 取回原始字节保存（实测能拿到完整原始文件），
  扩展名按真实 MIME 推导（不再出现 `.bin`）。

### v1.1.0
- **新增**：主世界钩子，支持 `new Audio()` 等**游离（不插入 DOM）的播放器**——修掉米游社 wiki 角色语音抓不到的问题。
- **新增**：标题智能提取。没有 `mediaSession` 歌名时，顺着"刚点击的那一行"取名字。
- **新增**：设置项「纯嗅探兜底」。
- **优化**：音频总时长下限 6 秒 → 3 秒。

### v1.0.0
- 首个版本：检测 `<audio>/<video>` 播放、简洁卡片、直连下载、blob 流录制、整页音频录制。
